Project: Enriquez Project  
Version: v1  
Date: 2026-03-07  
Purpose: Track and control scope, content, or implementation changes during Phase 1.

## 1) Change Control Rules
- Log every requested change before work begins.
- Classify impact: `Scope`, `Timeline`, `Quality`, `Risk`, `Cost`.
- Approve or reject each request explicitly.

## 3) Impact Assessment Checklist
- Does this change affect any `P1` launch gate?
- Does this change require new assets or approvals?
- Does this change alter CTA routing or tracking?
- Does this change introduce compliance review requirements?
- Does this change modify launch date assumptions?

## 4) Approval Workflow for Changes
1. Log request with impact assessment.
2. Assign owner and target decision date.
3. Review in weekly stakeholder update.
4. Record final decision in this log and `phase1-decision-log.md` if strategic.
5. Update impacted docs and tracker rows.
