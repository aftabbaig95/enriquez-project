# Scope Phases

Project: Enriquez Project  
Version: v1 scope framework

## 1) Scope Philosophy
This project should be managed as a phased digital funding funnel initiative, not as a single redesign task.

Each phase has a distinct objective:
- Phase 1: trust-building and conversion structure.
- Phase 2: functional features with custom logic.
- Phase 3: operational and backend enhancements.

## 2) Workstream Categories (Persistent)
## A. Visual / UX / Branding
- Navigation, layout hierarchy, page structure.
- Messaging placement and credibility sequencing.
- Mobile and desktop usability improvements.

## B. Functional Features
- Calculators, qualification estimators, logic-based tools.
- Enhanced intake interactions and guided flows.
- Dynamic content modules and richer media interactions.

## C. Backend / Operations
- Structured lead storage.
- Routing and assignment workflows.
- CRM/automation integration and reporting foundations.

## 3) Phase 1: Core Website Revamp
Objective: improve trust, clarity, and lead conversion flow.

In-scope deliverables:
- Updated sitemap and navigation.
- High-conversion homepage structure.
- Core pages launched:
  - Home
  - ISO Partnerships
  - Resources (planning-level if tools are phase 2)
  - Testimonials
  - Contact
  - Company Principles
  - Apply Now entry page
- Improved CTA strategy across key sections.
- Better media/testimonial placement and trust architecture.

Likely exclusions (unless explicitly added):
- Advanced calculator logic.
- Eligibility checker engine.
- CRM-level lead database.
- End-to-end automated follow-up workflows.

Success metrics:
- Higher conversion rate from visitor to application start.
- Improved time-on-page and scroll completion on key pages.
- Increased partner inquiry clarity from ISO page traffic.

## 4) Phase 2: Functional Features
Objective: add conversion-supporting tools that require custom logic.

Candidate deliverables:
- Cost of Capital calculator (production logic + guardrails).
- Payment or funding estimator tools.
- Eligibility checker with lead capture handoff.
- Improved Apply flow with clearer qualification context.
- Enhanced testimonial and media interactions.

Dependencies:
- Confirm formulas, disclosures, and compliance language.
- Validate user input requirements and result messaging.
- Define integration path between tools and intake endpoint.

Success metrics:
- Tool engagement rate.
- Calculator completion rate.
- Lift in qualified applications after tool usage.

## 5) Phase 3: Backend and Operational Enhancements
Objective: reduce lead loss and improve internal execution.

Candidate deliverables:
- Structured lead/application data store.
- Internal lead status workflow.
- CRM integration or workflow automation.
- Notification and follow-up triggers.
- Analytics dashboard and funnel reporting.

Dependencies:
- Selection of CRM or internal data model.
- Privacy/security requirements.
- Ownership and process definitions across the team.

Success metrics:
- Faster response time to new leads.
- Lower lead leakage.
- Better visibility into funnel performance and close rates.

## 6) Commercial/Scoping Guardrails
- Functional features are estimated and approved separately from page styling work.
- Backend enhancements are scoped as operational systems work, not page-level add-ons.
- Each phase requires acceptance criteria before progressing.

## 7) Recommended Sequence
1. Finalize phase 1 architecture and content inventory.
2. Launch phase 1 core pages with conversion-ready structure.
3. Prioritize one or two high-impact phase 2 tools.
4. Implement phase 3 workflow backbone once volume validates ROI.

## 8) Immediate Next Planning Outputs
- Technical audit with risk levels.
- Content readiness checklist.
- Functional requirements draft for first calculator.
- Lead intake journey map from click to follow-up.
