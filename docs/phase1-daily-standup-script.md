# Phase 1 Daily Standup Script

Project: Enriquez Project  
Version: v1  
Date: 2026-03-07  
Purpose: Keep daily execution updates concise and tied to blockers, owners, and next actions.

## 1) Standup Format (15 Minutes)
- 2 minutes: Delivery snapshot
- 8 minutes: Owner updates
- 3 minutes: Blockers and escalation decisions
- 2 minutes: Confirm next 24-hour actions

## 2) Facilitator Opening Script
"Today we will review P1 progress, blockers, and owner actions for the next 24 hours. Keep updates concise and action-oriented."

## 3) Delivery Snapshot Prompt
- P1 status today: [X complete / Y in progress / Z blocked]
- Top blocker: [Item]
- Milestone at risk: [M# or none]

## 4) Owner Update Prompt (Per Owner)
- What did you complete since last standup?
- What will you complete before next standup?
- What blocker needs escalation now?

## 5) Blocker Triage Script
- Blocker ID: [ID]
- Impact: [Scope/Timeline/Quality/Risk]
- Owner: [Name]
- Resolution owner: [Name]
- Due by: [Date/Time]
- Escalate now? [Yes/No]

## 6) Closeout Script
"Confirmed next actions are logged in the action register with owners and due dates. Any P1 blocker unresolved by end of day is escalated."

## 7) Daily Checklist
- Update `phase1-action-register-YYYY-MM-DD.md` statuses.
- Update `content-production-tracker-phase1.md` for changed P1 rows.
- Update `phase1-open-questions-register.md` for unresolved decisions.
- Update `phase1-risk-register.md` if risk profile changed.
