# Phase 1 RACI Matrix

Project: Enriquez Project  
Version: v1  
Date: 2026-03-07  
Purpose: Clarify responsibility, accountability, consultation, and information flow across Phase 1.

## 1) Role Key
- `PL`: Project Lead
- `UX`: Design/UX Lead
- `CL`: Content Lead
- `BL`: Build Lead
- `QA`: QA Lead
- `OL`: Ops Lead
- `CO`: Compliance Lead
- `LL`: Launch Lead

## 3) RACI Usage Rules
- Every `P1` task must have one `A` and one `R`.
- If no owner is assigned, the task is treated as blocked.
- Update this matrix if roles change.
