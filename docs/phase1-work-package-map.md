# Phase 1 Work Package Map

Project: Enriquez Project  
Version: v1  
Date: 2026-03-07  
Purpose: Group Phase 1 execution into manageable work packages with explicit outputs.

## 1) Work Packages

| WP ID | Name | Scope | Primary Outputs | Owner Role | Exit Criteria |
|---|---|---|---|---|---|
| WP-01 | Structure and IA Lock | Finalize page structure and navigation alignment | `wireframe-phase1.md`, `page-inventory.md` | Design/UX Lead | Section order and CTA hierarchy approved |
| WP-02 | Copy and Messaging Lock | Finalize launch copy direction and priorities | `wireframe-copy-placeholders-phase1.md`, tracker updates | Content Lead | `P1` copy blocks at Ready/Approved |
| WP-03 | Asset Intake and Validation | Collect, validate, and approve proof/media assets | `phase1-asset-request-packet.md` | Content Lead | Minimum launch-safe proof pack approved |
| WP-04 | Build Execution | Implement core pages and CTA flow | Build backlog execution + `phase1-build-handoff-spec.md` | Build Lead | `P1` tickets completed per acceptance criteria |
| WP-05 | QA and Hardening | Validate conversion-critical paths and resolve defects | `phase1-qa-test-case-matrix.md` | QA Lead | All `P1` QA tests pass |
| WP-06 | Launch Governance | Go/no-go checks, runbook execution, communications | Launch checklist + runbook + comms plan | Launch Lead | Launch gates done and stabilization complete |
| WP-07 | Reporting and Transition | Weekly reporting, KPI monitoring, phase closeout | Dashboard/KPI reports + completion template | Project Lead | Completion report drafted and Phase 2 brief prepared |

## 2) Dependency Flow
- WP-01 must finish before WP-04 full execution.
- WP-02 and WP-03 feed WP-04 and WP-05.
- WP-05 is required before WP-06 go decision.
- WP-07 begins in parallel after first weekly reporting cycle and completes post-launch.

## 3) Work Package Handshake Points

| Handoff | From | To | Required Evidence |
|---|---|---|---|
| H-01 | WP-01 | WP-04 | Approved structure and CTA route map |
| H-02 | WP-02/WP-03 | WP-04 | Approved copy blocks and validated assets |
| H-03 | WP-04 | WP-05 | Completed tickets + implementation evidence |
| H-04 | WP-05 | WP-06 | QA pass summary and defect status |
| H-05 | WP-06 | WP-07 | Launch status and initial KPI snapshot |

## 4) Weekly Tracking Fields
- Work package status: `Not Started`, `In Progress`, `Blocked`, `Done`
- Owner
- Planned finish date
- Current blockers
- Next action
