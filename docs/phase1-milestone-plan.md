## 2) Milestone Gate Criteria

### M1 Gate
- Home/ISO/Testimonials/Contact/Apply structures approved.
- CTA hierarchy and naming agreed.

### M2 Gate
- P1 copy blocks reviewed.
- Proof/media minimum launch set approved.
- Canonical apply URL and tracking standard confirmed.

### M3 Gate
- All P1 implementation tickets complete.
- Known limitations documented.

### M4 Gate
- All P1 QA tests pass.
- No unresolved critical defects.

### M5 Gate
- All critical launch readiness gates done.
- Rollback owner and communication plan confirmed.

### M6 Gate
- T+15 and T+45 smoke checks pass.
- Operational routing validated.

### M7 Gate
- Completion report and lessons learned captured.
- Phase 2 transition brief prepared.

## 3) Milestone Risk Flags
- `Red` if milestone date is missed with no approved recovery plan.
- `Yellow` if dependency remains blocked inside 48-hour window.
- `Green` when evidence complete and accepted.
