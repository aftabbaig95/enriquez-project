# Phase 1 Asset Request Packet

Project: Enriquez Project  
Version: v1  
Date: 2026-03-07  
Purpose: Standardize requests for missing assets required to complete Phase 1 build and launch.

## 1) Instructions
- Use this packet to request, track, and approve missing assets.
- One row per required asset.
- Mark all launch-critical assets with `P1` priority.

## 2) Asset Status Key
- `Requested`: Request has been sent.
- `Received`: Asset file delivered but not validated.
- `Validated`: Format/quality/legal checks complete.
- `Approved`: Cleared for launch use.
- `Blocked`: Missing or unusable; requires escalation.

## 5) Validation Checklist Per Asset
- File type and format match requested spec.
- Quality check passed (resolution/audio/readability).
- Naming conventions applied.
- Legal/consent status confirmed.
- Mapped to page section and block ID.

## 6) Escalation Rules
- Any `P1` asset not `Received` by due date: escalate to Launch Lead.
- Any `P1` asset not `Validated` within 24 hours of receipt: escalate to Content Lead.
- Any consent/legal uncertainty: escalate to Compliance Reviewer.
