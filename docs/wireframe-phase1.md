# Phase 1 Wireframes (Low-Fidelity)

Project: Enriquez Project  
Date: 2026-03-07  
Primary reference URL: https://purposefundgrp.com/  
Input sources: screenshot baseline + sitemap + meeting notes + live site capture

## 1) Wireframe Rules

- Focus on structure, message order, and CTA flow.
- Keep annotation labels: `KEEP`, `REFINE`, `ADD`, `MOVE`, `REMOVE`.
- Prioritize dual audience paths: Business Owner and ISO Partner.
- Keep this phase aligned to trust + conversion, not polished UI design.

## 2) Live Site Validation Notes (Homepage)

Confirmed from live site (`https://purposefundgrp.com/`):

- Hero line currently used: "Build your business, grow your wealth."
- Current core CTAs include `APPLY NOW`, `APPLY WITH US`, and phone `(917) 730-0705`.
- Current value blocks include:
  - Stress-Free Application & Approval Process
  - Easy Financing Solutions
  - Expert Advisors
- Current FAQ includes:
  - How long is the funding process?
  - What if I don't have a great credit score?
  - Are there penalties if I pay my balance off early?
- Footer and utility elements include privacy/compliance links and cookie notice.

Wireframe impact:

- Keep the current high-performing core promise language, but refine hierarchy and trust depth.
- Preserve the FAQ concept and move it to support objection handling before final CTA.
- Retain phone CTA as a secondary action where high intent is expected.
