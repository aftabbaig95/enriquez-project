# Live Site Wireframe Package

This folder is a separate, openable wireframe package based on live content from:
- https://purposefundgrp.com/

## What Is Included
- `index.html`: Multi-page wireframe hub with real homepage copy and CTA text.
- `assets/styles.css`: Shared styles and responsive layout.
- `pages/content-source.md`: Source map of live text blocks used in the wireframe.

## Open It
- macOS command:
  - `open wireframes/live-site-wireframe/index.html`

Optional local server:
- `cd wireframes/live-site-wireframe && python3 -m http.server 8080`
- Open `http://localhost:8080`
